# 多语言

[English](../i18n.md) | **简体中文**

框架翻译自己的界面文案。它从不翻译索引写的任何东西 —— 它只是把你写的内容,按读者
正在看的语言渲染出来。

```jsonc
"languages": ["en", "zh", "zh-Hant"]
```

第一个语言是默认语言,位于站点根;其余的在 `/<tag>/` 下生成完整的静态站点。翻译
后的页面是真实 URL 上的真实 HTML,可被索引、可被分享,而不是前端重渲。

内置界面语言:`en`、`zh`(简体中文)、`zh-Hant`(繁體中文)。常见标签会被归一化
—— `zh-CN`、`zh-Hans`、`zh-SG` → `zh`;`zh-TW`、`zh-HK`、`zh-MO` → `zh-Hant`。

## 你自己的文案

凡是索引提供的字符串 —— 在 `.xpkgindex.json` 里,或来自插件 —— 都可以写成按语言的
map,而不是一个字符串:

```jsonc
"site": {
  "title": { "en": "mcpp Package Index", "zh": "mcpp 包索引", "zh-Hant": "mcpp 套件索引" },
  "description": { "en": "Modular C++23 packages", "zh": "模块化 C++23 包" }
},
"install": { "primary": { "label": { "en": "Install mcpp", "zh": "安装 mcpp" } } },
"docs": { "cta": { "title": { "en": "Quick start", "zh": "快速开始" } } }
```

纯字符串表示「每种语言都一样」,所以单语言索引什么都不用改。

解析顺序:精确标签(`zh-Hant`)→ 主语言子标签(`zh`)→ 站点默认语言 → 任意已有
值。翻译只做了一半的配置,在每种语言下也都能渲染出东西,而不是一片空白。

### 插件里

同一套 map 适用于分面标签、分面值、区块标题、徽章、行内标签和提示:

```python
def _t(en, zh, hant):
    return {"en": en, "zh": zh, "zh-Hant": hant}

Facet(key="surface", label=_t("how you use it", "怎么用", "怎麼用"))
Block(kind="kv", title=_t("Build", "构建", "建置"), data={"items": items})
```

**标识符不要动。** `import`、`#include`、`modules`、`targets`、`programs`、
`aliases` 要么是读者真正要敲的,要么就是清单文件里的字段名。有人拿包页面和 `.lua`
描述符对照时,需要在两边看到同一个词。

### `index.json`

其中的按语言 map 会被展平成站点的默认语言。`index.json` 是一个 URL 上的一份文档,
schema 1 承诺的是字符串;一个消费者在期待标签的地方突然收到
`{"en": …, "zh": …}` 就会挂。翻译活在渲染出来的页面里。

## 文档

文档条目声明自己的译文,正文跟随页头的语言切换器:

```jsonc
{ "slug": "quick-start", "title": { "en": "Quick start", "zh": "快速开始" },
  "path": "docs/quick-start.md",
  "translations": { "zh": "docs/zh/quick-start.md" } }
```

没有对应译文的语言,会退到它能拿到的最接近的那份 —— 繁体页面退到简体文档而不是
英文,只写了英文文档的索引在所有语言下都显示英文。这对维护者实际写了什么是诚实的。

页面标题与导航名字由两条规则决定:

- **页面标题**是文档自己的 `# H1`,并从正文中移除,所以不会出现两次。
- **导航名字**优先用配置里的 `title`,前提是它显式写了当前语言 —— 那是专门为导航
  写的短名字,而且在文档本身没有翻译时,它是唯一可能正确的东西。否则用 H1。

### 手写的语言行

为了在 GitHub 上也能读,文档常常以这样一行开头:

```markdown
# 快速开始

[English](../quick-start.md) | **简体中文**
```

在站点上那是第二个、而且更差的切换器,还指向裸 `.md` 文件,所以会从渲染页面中
移除。判定是精确的,而不是去猜「语言行长什么样」:开头那个段落里的链接**全部**
指向这篇文档已声明的其他译文。指向别的文档的普通链接属于正文,会被保留。

## 访客那边发生了什么

首次访问时,语言由 `navigator.languages` 与页面头部的 `hreflang` 备选项比对得出,
跳转时保留查询串。访客一旦从切换器里选过语言,该选择会被记住,自动跳转从此不再
覆盖它。

主题同理:在访客动过开关之前,一直跟随系统设置。

## 新增一种界面语言

界面文案表在 `xpkgindex/i18n.py`:加一份键相同的字典,注册进 `CATALOG` 和
`LANGUAGE_NAMES`,补上标签别名,它就对所有索引可用了。缺失的键回退到英文,而不是
渲染成空白。
